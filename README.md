# KIRIEMON

入力した文字をQRコードに変換するサイト。
KIRIEMON用に設計されています。

## ローカルで開く

リポジトリのルートで `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist` を実行し、ブラウザーで `http://127.0.0.1:8000/` を開きます。

## QRコードの仕様

入力できる文字
tenji.jsonファイル内で対応している文字と記号が使えます
あ〜ん
、小さい文字や濁音・半濁音を含むひらがな（ぁ〜ん・ゔ・ゕ・ゖ）・カタカナ（ァ〜ヶ）、長音（ー）、句読点（！？。、）、半角・全角スペースです（60字以内）。半角カタカナも入力でき、濁点や半濁点を含めてひらがなに変換してからQRコードに格納します。結果画面の文字は入力どおりに表示します。半角ハイフン（-）、改行、タブは入力できません。濁点や半濁点が別の文字として入力された場合は、合成できる組み合わせを1字にまとめてからQRコードに変換します。生成には、
MITライセンスの [Project Nayuki QR Code generator v1.8.0](https://github.com/nayuki/QR-Code-generator/releases/tag/v1.8.0) を使用しています。
